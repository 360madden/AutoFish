# Archived Rift Script Artifacts

This folder stores **retrievable Rift-specific script artifacts** gathered during research.

## Purpose

- preserve public script/source material before links disappear
- separate **full archived artifacts** from **reference-only sources**
- keep untrusted third-party code out of the production source tree

## Trust / safety

- Everything here should be treated as **untrusted third-party code**.
- These artifacts were archived for study and comparison only.
- Do **not** run them without isolated review.
